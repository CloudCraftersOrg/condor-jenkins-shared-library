Builds the Dockerfile in the workspace, pushes to ECR tagged
jenkins-<commit SHA> (not the bare SHA - avoids colliding with another
pipeline, e.g. GitHub Actions, that already tagged the same commit on
an immutable-tag repo), and sets env.IMAGE_DIGEST to the pushed digest.

condorEcrBuildPush(
    repository: 'condor-myapp',
    region: 'us-east-1', // optional, defaults to us-east-1
)

Downstream steps should deploy by digest (env.IMAGE_DIGEST), not the
mutable tag.
